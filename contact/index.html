Contact FileForge

Found a bug, hit a file that will not convert, or want a tool added? Send a note. The form below opens your own email client — FileForge has no server that can receive messages, so it never claims to send one for you.

This site has no server mailbox, so the form cannot deliver a message by itself. Submitting opens your own email client with the text filled in, addressed to hello@toolnest.example.com — a placeholder address in this build.

Before you write

  • If a conversion failed, the error message shown in the tool is usually the useful part — include it.
  • Please do not send documents you need to keep private. Support requests should describe the problem, not attach the file.
  • Tools labelled “Worker required” are not wired up yet, so reports about them are feature requests rather than bugs.
