Frequently asked questions

How FileForge processes files, what the limits are, and why some tools are labelled differently.

Are my files uploaded to a server?
For browser tools, no. PDF creation, rendering, merging, splitting, rotating, compressing and the document, data and archive tools all run inside your browser tab. The only exception is the image API group (compress, resize, format conversion), which posts your image to the FileForge server, processes it in memory with Sharp and streams the result back. Nothing is written to disk.
Why does one tool say “Worker required”?
Office, OCR, audio, video and large-file conversions need heavyweight engines that cannot run safely inside a browser tab. Those tools are registered in the tool registry with a clear “Worker required” label instead of a button that pretends to work. The README documents the worker architecture (queue, isolated container, temporary storage, automatic deletion) that a production deployment plugs into.
What are the file size limits?
Browser tools accept up to 25 MB per image and 100 MB per PDF. The image API route accepts up to 25 MB per upload by default, configurable with the MAX_UPLOAD_MB environment variable. Very large images are downscaled before drawing to a canvas so the tab does not run out of memory.
How does PDF compression actually work?
Each page is re-rendered to a raster image and the PDF is rebuilt from those images. That reliably shrinks image-heavy documents, but it turns text and vector artwork into pixels, so a small vector-only PDF can end up larger. The result panel always shows the real before and after sizes rather than a promised percentage.
Which image formats can I convert to PDF?
JPG/JPEG, PNG and WEBP for the image-to-PDF tools. PNG sources stay lossless when the image quality setting is 100. BMP, HEIC, TIFF and SVG are handled by their own tools.
Can I reorder pages before creating the PDF?
Yes. Drag a file to a new position, or use the move up and move down buttons. Each image can also be rotated 90° before the PDF is built.
Does FileForge add watermarks or limit downloads?
No. There are no watermarks, no download counters and no account requirement. The only files that leave the page are the ones you download.
What happens to the files the server API touches?
The upload is buffered in memory, decoded, encoded and returned in the same request. It is never written to a temporary directory, never queued and never logged. The response is sent with Cache-Control: no-store.
Which browsers are supported?
Any modern browser with canvas, WebAssembly and Web Worker support: current Chrome, Edge, Firefox and Safari. Mobile browsers work too - the interface is responsive from 320 px upward.
Is there an API for developers?
The image conversion route (/api/convert) is a plain HTTP endpoint you can call with multipart form data. It is rate limited per IP and validates the real file signature rather than the browser's Content-Type header. A public API with keys is not part of this release.
